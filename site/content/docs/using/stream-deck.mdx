---
title: "Stream Deck"
description: "Keys for an Elgato Stream Deck."
---

An Elgato Stream Deck plugin ships in the repository (`integrations/streamdeck`): Play / pause, Next, Previous and a Now playing key with the title and artist. It talks to Legato’s phone remote on this PC or your own network, and to nothing else.

1. Turn on Settings › Playback › Phone remote and copy the link it shows.
2. Copy the `app.legato.deck.sdPlugin` folder into `%APPDATA%\Elgato\StreamDeck\Plugins` and restart the Stream Deck software.
3. Drag a Legato key onto the deck and paste the link in its inspector.

Not tried on a real Stream Deck yet: tell us on GitHub if a key misbehaves.
